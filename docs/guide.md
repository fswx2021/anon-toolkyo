# 使用指南

[项目首页](../README.md) · [开发与发布](development.md)

## 安装与更新

1. 下载 `anon-toolkyo-版本号.apk`，在手机上打开安装。正式版适用于 Android 8.0 及以上，包含 ARM64 和 x86-64。 [Gitee 发行版](https://gitee.com/fswx2021/anon-toolkyo-updates/releases) · [GitHub 最新版](https://github.com/fswx2021/anon-toolkyo/releases/latest)
2. 首次安装且来源尚未设置时，可在「设置内容来源」选择「一键聚合并启用」。四个栏目的进度会分别显示，可重试未完成项。之后也能从「设置 → 一键聚合四个模块」打开。
3. 从底部选择「音乐」「漫画」「小说」或「动画」。本地音视频和作品可直接导入，在线搜索使用已启用的来源。

正式版启动时会检查更新，也可手动进入「设置 → 关于与数据 → 检查更新」。从 0.30.5 正式版起，应用优先检查 Gitee，必要时回退到 GitHub。同一版本只显示一条更新提示。

点「应用内下载并安装」后，应用会下载并校验安装包，由 Android 确认安装。首次操作可能需要为本应用开启「安装未知应用」权限。「去网站下载」可打开对应发布页。签名一致的版本可以覆盖安装，保留曲库、书架和阅读进度。

## 音乐

### 导入和在线播放

- **本地文件**　「音乐 → 导入 → 导入文件」支持多选，也可从文件管理器分享音视频。应用会一并读取同名歌词文件，导入成功的文件可离线播放。
- **链接**　「导入 → 导入链接」支持公开 B 站视频、音频、合集和媒体直链。选择分 P 或合集条目时，请一次粘贴一个链接。B 站视频有独立音轨时优先保存音轨，HLS 播放需要联网。
- **搜索**　在音乐页输入歌名或歌手。已启用的来源并发搜索，结果按相关性排序。点曲目可播放，也可在搜索结果或播放页下载支持离线保存的曲目。
- **来源**　「音源管理」可聚合 MusicFree 清单，或导入订阅、本地 JSON 和 JS 插件信息。内置搜索涵盖 B 站公开内容、Audius、Internet Archive 的 Creative Commons 音频和猫耳FM 免费内容。受播放保护的猫耳FM 条目可在原站打开。可配置 Navidrome 搜索自有曲库。 [MusicFree 清单](https://github.com/maotoumao/MusicFreePlugins/blob/master/plugins.json) · [Audius API](https://docs.audius.co/api/) · [Internet Archive 元数据 API](https://archive.org/developers/md-read.html)

音频由 Android 系统解码，支持常见的 MP3、AAC、M4A、WAV、FLAC、OGG，以及带兼容音轨的 MP4、MKV 和 WebM。具体支持情况取决于手机与编码。

### 曲库、歌词与音效

- **队列**　从筛选列表或歌单开始播放时会生成对应队列。可指定下一首、调序和移除曲目。播放页支持倍速和定时停止。
- **歌词**　点「歌词」可添加歌词文件。支持 LRC、SRT、VTT、TXT 和部分 MP3、FLAC 内嵌歌词。点带时间轴的一句可跳转，手动浏览后可点「回到当前歌词」。部分 Audius 曲目可匹配在线同步歌词。 [LRCLIB](https://lrclib.net/docs)
- **音效**　播放页右上角提供人声、低频、夜间等预设，以及八段均衡器、动态平衡和耳机声场。选择「原声」可关闭应用音效并保留调节值。完整动态处理和耳机声场取决于系统与设备支持。
- **后台控制**　切到其它栏目后，音乐可继续播放。回到音乐栏目可使用迷你播放器，也能通过系统提供的通知栏或锁屏媒体控件操作。 [Android 媒体控件](https://developer.android.com/media/implement/surfaces/mobile)

## 漫画与小说

### 添加来源

从「管理漫画源」或「管理书源」选择「一键聚合」，应用会导入公开目录里的兼容规则，并启用新增来源。也可选择文件、粘贴规则或填写链接。导入预览会显示数量、新增、更新和跳过原因，混合来源会归入对应栏目。

| 来源 | 导入方式 |
| --- | --- |
| 异次元图源 | 粘贴图源或合集详情页及其 JSON 地址，也可选择图源文件或压缩合集。 [异次元图源目录](https://www.yckceo.com/yiciyuan/tuyuan/index.html) |
| 阅读 3.0 | 支持小说和漫画来源 JSON、`legado://import/bookSource?src=…` 链接，以及包含书源的阅读备份 ZIP。 [阅读项目](https://github.com/gedoor/legado) |
| 本地作品 | 小说可导入 TXT、EPUB，漫画可导入 CBZ、ZIP 或图片目录。 |

聚合还会读取部分公开的阅读与异次元来源合集。书站能否搜索、打开目录和阅读正文，以实际访问结果为准。 [阅读书源合集](https://www.yckceo.com/yuedu/shuyuans/index.html) · [AOAOSTAR](https://legado.aoaostar.com/) · [LuAnMuC](https://github.com/luanmuc/legado-book-sources)

### 搜索、换源与诊断

- 搜索会按作品名归并，点击结果可选择来源。精确匹配的书名和作者优先显示，也可用书名与作者组合查询。
- 「来源详情」会列出各来源的结果和失败原因。频繁失败的来源会暂缓搜索，可点「继续搜索」立即检查，或点「重试失败」延长单源时限并保留已有结果。
- 作品目录与阅读菜单都支持换源。切换时可匹配章节名或手动选章，原来源的阅读位置和书签会保留。
- 在来源管理中点「检查来源」，用已收录的作品名测试搜索、目录和正文。漫画还会尝试下载和解码首图。「批量体检」可复核多条来源，导出 TSV 诊断表，并由你确认要停用的来源。

### 阅读、书架与离线

- 轻点屏幕中央收起或唤出工具栏。底部进度条可在章内跳转，翻过末页或滚动到章末后继续上滑可进入下一章，从章首往回翻可接到上一章末尾。
- **漫画**可选从右向左、从左向右或纵向长条。支持缩放、相邻页预加载、单页重试、裁切白边和宽屏双页。
- **小说**可选滚动、左右翻页和音量键翻页，支持调整主题、字体和排版。菜单提供章内查找、系统朗读和正文清理。
- **书架与下载**支持封面网格、详细列表、分组和检查收藏更新。点「⋯ → 从书架移除」后，仍可从历史续读，或在「管理书架 → 已移出书架」放回。可从目录批量下载，下载完成的章节可在「离线下载」打开。
- 想先离线试用，可点「试读示例」，打开原创漫画《唱针落下的夜晚》或短篇小说《潮汐电台》。

## 动画

### 找番和播放

1. 从底部「动画」浏览热门番剧、排行榜或放送日历，也可搜索片名、以图搜番。
2. 在「规则仓库」选择「一键聚合」安装来源，或导入兼容规则。点番剧进入作品详情，选择来源和集数播放。 [Kazumi 规则仓库](https://github.com/Predidit/KazumiRules) · [Bangumi 动画频道](https://bangumi.tv/anime)
3. 在播放器中切换集数或线路。按集查看评论时，可展开回复。在首页打开「追番」「历史」或「下载」，即可查看收藏、续播记录和离线任务。

横屏时轻点画面收放控件，双击播放或暂停，横滑调进度。可在更多选项中调整倍速和画面比例，选择适用的字幕轨，或锁定控件。视频、图片、分集评论和弹幕由对应的来源或数据服务提供。

### 弹幕

在播放器底部点「弹」开关。应用按作品和集数匹配弹幕，默认可使用 uosc_danmaku 社区服务。可手动换作品或集数、筛选来源、调节范围和透明度，也可以导入哔哩哔哩格式的本地弹幕 XML。 [uosc_danmaku 说明](https://github.com/Tony15246/uosc_danmaku#弹幕解析服务相关)

已取得开放平台凭证的用户可在弹幕设置中切换弹弹play直连。 [弹弹play开放平台](https://doc.dandanplay.com/open/)

## 历史与备份

- **历史**　四个栏目首页都可查看历史记录、最近一次时间和次数。漫画和小说可接着上次的位置阅读，动画可续播剧集。旧记录缺失的统计会标为未记录。
- **本机备份**　「设置 → 备份与恢复」可导出 ZIP。轻量备份包含设置、索引、进度和歌词等资料，完整备份还包含音乐文件、本地作品及离线章节。恢复时应用会先验证备份，确认并重新打开后应用恢复。
- **动画同步**　全局备份涵盖旧版动画资料。当前动画收藏和观看记录可在「动画 → 同步」管理，按需使用 Bangumi 或 WebDAV。
- **开源声明**　从「设置 → 开源声明」可查看项目网站、发行版与许可证。页底「致谢」列有复用项目、上游源码和相关许可。 [第三方声明](../THIRD_PARTY_NOTICES.md)
